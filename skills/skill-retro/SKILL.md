# 溜まった作業記録から skill を直す

`tmp/` は追跡しない。**`done/` の中身は、次の振り返りまでしか存在しない。**
マシンが変われば消える。ここでやるのは、消える材料を追跡される場所へ移すことである。

移す先は skill の 1 文、`// TODO(未決定)`、`research-handoff/blocking-decisions.md`、
ADR、コミット本文のいずれかである。**「行き場なし」を黙って消さない。**

## 1. 対象を並べる

    ls -1 tmp/done/

各作業ディレクトリの `plan.md` `review.md` `impl-result-*.md` を読む。
`impl-prompt-*.md` は plan からの派生物なので読まない。

## 2. 手順の欠陥へ翻訳する

`review.md` で `事前検出: 可` と判定された指摘は、**実装前に検出できたのに検出しなかった**
という意味である。文書の側に欠陥がある。指摘 1 件につき次を行う。

1. **どの文書の欠陥かを 1 つに決める。** 書き手側 (`start-implementation` の `plan.md` の書式) か、
   読み手側 (`implement-approved-plan` の手順) か、今回限りの事故か。
   両方に足すと同じ事故へ手順が 2 か所できるので、**片方に決める**。上流のほうが安い
2. **1 文に落とす。** 自問は「この文が無かったら今回も検出できなかったか」。
   「慎重に確認する」の類は耐えないので足さない
3. **書いた直後に `skill-lint` が鳴ったら従う。** 行数の警報ラインを超えたら、足すのをやめて削る対象を探す

`事前検出: 不可` の指摘は、実装するか実行するかしないと分からなかったものである。**文書を触らない。**
この分岐が本体であって、大半はここへ落ちる。全件が `可` になるなら判定が甘い。

**複数の作業ディレクトリに同じ欠陥が出ていないかを見る。** 1 回なら事故だが、
2 回目は手順の問題である。まとめて振り返る利点はここにしかない。

行き先は `.agents/skills/` とは限らない。`start-implementation` のような共通の skill は
chezmoi の `$(chezmoi source-path)/skills/` が正本で、このリポジトリの git には残らない。
**直した場所をユーザーへ伝える。**

## 3. 残りの行き場を確かめる

| 中身 | 既に残る場所 | 残っていないときの行き場 |
|---|---|---|
| `plan.md` の `概要` `要件` `方針` `リスク` | コミット本文 (規約) | コミットが規約どおりか確かめる |
| `impl-result` の「満たせなかった要件」 | どこにもない | 次の plan、または `research-handoff/blocking-decisions.md` |
| `impl-result` の「前提として置いたこと」 | どこにもない | `// TODO(未決定)` かコミット本文 |
| `impl-result` の「`TODO(未決定)` を残した箇所」 | コード | `grep -rn "TODO(未決定)" src scripts` で実在を確かめる |
| `review.md` の却下した指摘 | どこにもない | `// TODO(未決定)` か `blocking-decisions.md` |
| 撤回しにくく長期的な影響を持つ設計判断 | — | `adr-writing` で ADR |
| 計画を変えた理由 | — | `tmp/dig/` |

## 4. 提案して、承認を得てから消す

直したものと、行き場を移したものを 1 行ずつ挙げる。

```text
直した: <file> — <どの記録から、何を根拠に、何を足したか>
移した: <どこから> → <どこへ> — <何を>
行き場なし: <何が> — <消してよいか>
```

**承認が無ければ消さない。** 承認を得たら `tmp/done/` を空にする。

    rm -rf tmp/done/<NNNN_name>

`tmp/dig/` と生きている `tmp/<NNNN_name>/` は消さない。**消すのは `done/` の中だけである。**

## やらないこと

- skill 本文どうしの食い違いを探さない (`skill-audit` の仕事)
- 改善点を埋めるために無理に問題を作らない。`事前検出: 不可` ばかりなら、そう報告して終える
