# Herdr Keymap

> Prefix: **Ctrl-a**
> 閉じる: **q / Esc** · 移動: **j / k / ↑ / ↓** · 検索: **/**

## ◇ ペイン（分割画面）

- `Ctrl-a v` — 右に分割
- `Ctrl-a -` — 下に分割
- `Ctrl-a h/j/k/l` — 左・下・上・右へ移動
- `Ctrl-a r` — リサイズモード（`h/j/k/l`で調整、`Esc`で終了）
- `Ctrl-a z` — ズーム
- `Ctrl-a Tab` / `Ctrl-a Shift-Tab` — 次・前のペイン
- `Ctrl-a x` — ペインを閉じる
- `Ctrl-a Shift-p` — ペインに名前を付ける

## ◇ タブ（tmuxのウィンドウ相当）

- `Ctrl-a c` — 新規タブ
- `Ctrl-a 1..9` — 番号で移動
- `Ctrl-a n` / `Ctrl-a p` — 次・前のタブ
- `Ctrl-a Shift-t` — 名前を変更
- `Ctrl-a Shift-x` — 閉じる

## ◇ Space（プロジェクト相当）

- `Ctrl-a w` — ピッカーで一覧・切替
- `Ctrl-a Shift-n` — 新規作成
- `Ctrl-a Shift-w` — 名前を変更
- `Ctrl-a Shift-d` — 閉じる（確認あり）
- `Ctrl-a q` — detach（セッションは維持）

復帰はシェルで`herdr`、完全停止は`herdr server stop`。

## ◇ Git / worktree

- `Ctrl-a g g` — LazyGitを開く
- `Ctrl-a g n` — worktreeを作成
- `Ctrl-a g o` — 既存worktreeを選んで開く
- `Ctrl-a g d` — 現在のmanaged worktreeを削除（確認あり）
- `Ctrl-a g q` / `Ctrl-a g Esc` — キャンセル

## ◇ スクロールバック / コピー

- マウスホイール — スクロールバックを表示
- ドラッグ選択 — コピー
- `Ctrl-a e` — スクロールバックをエディタで開く

## ◇ その他

- `Ctrl-a ?` — このチートシート
- `F1` — 全キーバインド一覧
- `Ctrl-a s` — 設定画面
- `Ctrl-a Shift-r` — 設定リロード
- `Ctrl-a b` — サイドバー表示切替
- `Ctrl-a o` — 通知のあったペインへ移動
- `Ctrl-a Ctrl-a` — アプリへ本来の`Ctrl-a`を送る

サイドバーにはagentの`working / blocked / done / idle`状態が表示されます。

---

`q`または`Esc`で閉じます。
